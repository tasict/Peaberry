隱私權政策

生效日期：2026 年 10 月 19 日

Peaberry 不收集任何東西，也不把任何東西送到任何地方。它想送也送不出去：這個 app 本來就沒有網路存取權限。

app 不會做的事

  • 不建立任何網路連線。它的 App Sandbox 權限裡沒有網路存取，就算它試著連線，macOS 也會拒絕。
  • 沒有分析、當機回報、廣告或追蹤，也沒有要登入的帳號。
  • 不收集任何個人資料。它在 App Store 上的隱私權標籤是「未收集資料」。

留在你 Mac 上的東西

  • 你的設定，包括情境與你輸入的程序名稱，存在這個 app 自己的偏好設定裡，只在你的 Mac 上，不會離開它。
  • 為了判斷要不要讓 Mac 保持清醒，Peaberry 會即時讀取你 Mac 上的資訊：正在執行的程序，以及你自己的程序的參數與 CPU 使用量（只在規則用得到時）；整體 CPU 負載；距離你上次操作鍵盤或滑鼠多久；電源與電池電量；其他讓 Mac 保持清醒的 app；排定的睡眠；以及在情境要用桌布遮住桌面時，你的桌布。這些資訊當下用完即止，不會送到任何地方。
  • 如果你以「選擇資料夾」的方式安裝 AI agent 技能，Peaberry 會保留那個資料夾的書籤，之後才能更新裡面的檔案。
  • 限時情境的提醒是本機通知，排程在你的 Mac 上。

來自其他程式的要求

  • 你 Mac 上的程式（例如 AI agent）可以透過 peaberry:// 連結要求 Peaberry 讓 Mac 保持清醒。一筆要求只帶有程序 ID 或分鐘數、一個簡短的名字，以及一句簡短的理由。
  • 要不要讓程式提出要求，是「設定 › AI agent」裡的一個開關，只有你能打開。在你打開之前，Peaberry 在「智能控制」下會先放行第一筆要求，最多 15 分鐘，免得進行中的工作白做；其他要求會在面板上等你回答。每一筆要求都會顯示在面板上，你隨時可以停止。
  • 你執行的程式可以透過 Peaberry 的命令列選項（--status、--brief）讀取它的狀態，其中包括你的規則比對到的程序名稱。這些都只在你的 Mac 上進行。

App Store

Peaberry 透過 Mac App Store 提供。下載與任何付款都由 Apple 依它自己的隱私權政策處理，你的付款資料不會到開發者手上。

這個網站

這個網站沒有分析工具、沒有 cookie，也沒有任何程式碼在你的瀏覽器裡執行。網站架在 GitHub Pages 上，GitHub 可能會依照 GitHub 一般隱私權聲明記錄造訪紀錄。如果你在 GitHub 上開 issue，你寫的內容是公開的，並適用 GitHub 的條款。

變更與聯絡方式

這份政策若有變更，新版會公布在這個頁面上，並更新生效日期。本政策提供 English、繁體中文、日本語與 Español 版本；各版本內容如有出入，以英文版為準。

有問題請到 github.com/tasict/Peaberry/issues 開一個 issue。
